# Ступени — английский каждый день

Веб-приложение для телефона и компьютера. Работает без интернета, без сборки и без зависимостей.
Прогресс хранится только на устройстве (localStorage). Его можно сохранить в файл и загрузить на другом устройстве (Настройки → Данные).

## Что внутри

- **Уроки по 30 минут**: 4 уровня (A1, A2, B1, B2), по 6 уроков. Каждый урок состоит из 6 шагов:
  слова (8 штук, с примерами и подсказками для запоминания) → правило (таблица, примеры, 3 частые ошибки) →
  практика (выбор, сборка фразы, написание) → аудирование (диалог, вопросы на слух, диктант) →
  произношение (микрофон, если браузер позволяет) → мини-тест (ответы показываются в конце).
  Если ответить с ошибкой, задание повторится в конце шага.
- **Карточки** с повторением по расписанию (1–3–7–14–30–60–120 дней). Слова урока попадают в карточки после урока. Можно добавить свои слова.
- **Наборы слов** (Карточки → «Наборы слов»): свои наборы, 10 готовых тематических (аэропорт, гостиница, ресторан, покупки,
  врач, работа, разговорные фразы, дом, чувства, фразовые глаголы — по 16), слова пройденных уроков. Свой набор вставляется
  списком: строка «слово — перевод — пример», разделитель тире, «;», «=» или табуляция (столбцы из Excel); русское первым — меняется местами.
  Шесть режимов: карточки, заучивание (выбор → письмо, ошибки возвращаются), письмо, на слух, подбор пар на время (рекорд), тест (ответы в конце).
  Прогресс слова: новое → знакомо (узнал) → выучено (написал без ошибки; ошибка в письме возвращает в «знакомо»).
  Кнопка «Добавить в повторение по расписанию» переносит слова набора в обычные карточки.
- **Практика**: работа над ошибками, тест недели (10 вопросов по урокам за 7 дней, ответы в конце), тест уровня,
  «Перевод и вопросы» (тестовый режим: перевести текст самому → сверить → вопросы по лексике, фразам и пониманию), справочник грамматики.
- **Прогресс**: серия дней, минуты, выученные слова, точность ответов, минуты за 2 недели, активность за 18 недель, трудные темы, тесты недели.

## Как открыть

- На компьютере: открыть `index.html` в Chrome или Edge. Всё работает, кроме установки на телефон и работы без сети.
- На телефоне: файлы нужно выложить на любой хостинг со ссылкой `https://` (например, GitHub Pages). Тогда:
  - в Chrome меню → «Добавить на главный экран» — приложение ставится как обычное;
  - работает без интернета (`sw.js`);
  - работает проверка произношения (микрофону нужен https).

Озвучка — встроенный голос телефона или браузера (настройки: США/Британия, скорость).
Распознавание речи в Chrome обычно идёт через интернет. Без сети этот шаг можно пропустить.

## Устройство

| Файл | Что |
|---|---|
| `index.html` | страница |
| `css/app.css` | оформление; цвета — переменные в `:root`, тёмная тема, цвет уровня — `[data-lvl]` |
| `js/app.js` | всё приложение: состояние, экраны, занятия, карточки, статистика |
| `js/content/a1.js … b2.js` | уроки уровней |
| `js/content/reading.js` | тексты для перевода и тест уровня |
| `js/content/sets.js` | готовые наборы слов `[слово, перевод, пример]` |
| `sw.js` | работа без интернета; **поменял файлы — подними `CACHE`** |
| `manifest.webmanifest`, `icons/` | установка на телефон |
| `tests/` | проверки (ниже) |

Хранение: `stupeni.v1` — прогресс (уровень, цель, уроки, карточки, дни, ошибки, тесты; `sets` — свои наборы, `setp` — прогресс наборов), `stupeni.run.v1` — незаконченное занятие
(урок можно закрыть и продолжить с того же места).

## Как добавить урок

В файле уровня вызвать `L({...})`:

```js
L({
  id: "a1-7", icon: "🍎", title: "Название", topic: "Тема правила коротко",
  words: [["word", "перевод", "Example sentence.", "Перевод примера.", "Подсказка, как запомнить"], ... ровно 8],
  rule: { title, text: ["абзац, можно <b>выделять</b>"], head: ["столбцы"], table: [["строки"]], note: "заметка",
          ex: [["Example.", "Пример."]], mist: [["Неверно.", "Верно.", "Почему"], ... ровно 3] },
  drills: [["Sentence with ___ gap.", ["верный", "неверный", "неверный"], "Перевод.", "Пояснение"], ... ровно 8],
  order: [["Phrase to build.", "Перевод"], ... 3],
  dialog: [["Имя", "Line.", "Реплика."], ... от 4, два участника]
});
```

Верный вариант в `drills` всегда **первый** (на экране варианты перемешиваются). Слова не должны повторяться между уроками.
После правок запустить `node tests/check.js`, он найдёт типичные ошибки.

## Проверки

```
node tests/check.js                     # содержание: число слов/заданий, пропуски, повторы, словарики
```
Сквозная проверка в браузере: урок целиком, разделы, карточки, тест недели, тест уровня, чтение, сверка ответов:
```
msedge --headless=new --disable-gpu --user-data-dir=<временная папка> --virtual-time-budget=15000 --dump-dom file:///<путь>/tests/smoke.html
```
Итог — в атрибуте `data-res` у `<body>` (`{"ok":82,"fail":[]}`).

Снимки экранов шириной телефона (390px):
- `tests/frame.html?v=stats` — экран с демо-прогрессом (`v` = home, course, cards, practice, stats, rule/a1-3, lesson/a2-2; `&theme=dark`);
- `tests/frame.html?p=runshot.html&id=a1-3&to=choice&wrong=1` — экран урока (`to` = word, choice, order, type, dialog, speak, result, review);
- `tests/frame.html?p=runshot.html&set=ts-food&m=match` — режим набора (`m` = flash, learn, write, listen, match, test).

## Что можно сделать дальше

- Больше уроков (по 10–12 на уровень) и текстов.
- Режим живого разговора через ИИ (нужен ключ и интернет).
- «Свой текст» в переводе (тоже через ИИ).
- Напоминание о занятии (уведомление), выкладка на хостинг.
